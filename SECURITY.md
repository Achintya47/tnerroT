# Security Policy

Thank you for helping keep **tnerroT** secure.

## Supported Versions

Security updates are provided only for the latest version of the project available on the `main` branch.

|     Version     | Supported |
| :-------------: | :-------: |
| Latest (`main`) |     ✅     |
|  Older versions |     ❌     |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** disclose it publicly by opening a GitHub issue.

Instead, report it privately by one of the following methods:

1. Open a **GitHub Private Security Advisory**, if available.
2. Contact the project maintainer through GitHub.

Please include, where possible:

* A description of the vulnerability.
* Steps to reproduce the issue.
* The affected version or commit.
* Any proof-of-concept or logs that help demonstrate the issue.
* Suggested mitigations, if known.

## Response Process

After receiving a report, the maintainer will:

1. Acknowledge receipt of the report as soon as reasonably possible.
2. Investigate and validate the reported issue.
3. Develop and test an appropriate fix.
4. Publish the fix and credit the reporter where appropriate (unless anonymity is requested).

## Responsible Disclosure

Please allow reasonable time for the vulnerability to be investigated and resolved before publicly disclosing technical details.

Responsible disclosure helps protect users of the project and enables coordinated fixes.

Thank you for contributing to the security of **tnerroT**.
